OS and cloud comparison

On a self-hosted server, the operator installs and patches the OS and web server. In this managed platform, the provider abstracts those layers; the student controls site files and configuration rather than the host kernel.

Security: HTTPS encrypts data in transit. It does not authorize visitors or make browser JavaScript secrets private.

Performance: Shared infrastructure reduces operational work but can introduce platform limits and variable performance.

Portability: HTML/CSS/JS are portable; deployment workflow and route configuration may be provider-specific.
