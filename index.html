Project introduction

What this project demonstrates

This three-page website explores the operating-system ideas behind cloud hosting: resource management, deployment automation, security boundaries, and service availability.

The project uses static HTML, CSS, and JavaScript. It does not need a database, a paid virtual machine, or personal information.

Build

Develop and test locally, then publish through a GitHub repository.

Deploy

Assignment 1 was hosted on Cloudflare Workers. Assignment 2 targets Cloudflare Workers Free with a managed API.

Evaluate

Inspect workflow logs, headers, routing, and deployment changes.

Privacy note

The checklist on the Progress page is stored only in this browser's local storage. It is not sent to a server.
